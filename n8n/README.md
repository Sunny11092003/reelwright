# n8n workflows

Importable JSON files generated by `scripts/generate-n8n-workflows.mjs`. See `docs/N8N_SETUP.md`.

| File | Trigger | Purpose |
|---|---|---|
| video-analysis.json | Webhook `/webhook/aca/video-analysis` | Runs video analysis stage, reports result |
| seo-generation.json | Webhook `/webhook/aca/seo-generation` | Runs SEO analysis stage |
| content-generation.json | Webhook `/webhook/aca/content-generation` | Generation + quality check |
| publishing.json | Webhook `/webhook/aca/publishing` | Publishes one job (Instagram, Facebook or WordPress) |
| scheduling.json | Every minute | Claims due scheduled posts and publishes each |
| analytics.json | Webhook + every 6 hours | Pulls platform metrics |
| error-handler.json | Error Trigger | Reports workflow errors to the backend log |

Required n8n environment: `N8N_BLOCK_ENV_ACCESS_IN_NODE=false`, `ACA_BACKEND_URL`, `ACA_INTERNAL_SECRET`, `ACA_WEBHOOK_SECRET`.
